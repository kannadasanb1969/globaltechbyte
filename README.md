## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Cloudflare Pages
Use these settings:
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`

Connect the project repository to Cloudflare Pages or upload the generated `dist` folder using Cloudflare's Pages deployment flow.
